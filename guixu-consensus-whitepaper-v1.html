第一章 项目背景与愿景

2026年，算力仍在矿场集中，节点仍在服务器集群中沉默运转。普通人的闲置电脑、手机、宽带上限与存储空间，从未被纳入区块链的共识网络。算力与网络的集中化，让去中心化的口号在现实中变得苍白。

归墟共识网络，诞生于这样一个朴素的信念：真正的去中心化，不应该要求任何人放弃自己的设备。每个人手头的闲置资源，本身就是区块链最需要的共识力量。

命名释义

归墟 (Guixu) · The Great Abyss

归墟是中国古代神话概念，最早见于《列子·汤问》。归墟指海水汇聚的无底之渊，所有江河最终汇入归墟，但归墟的水量却永不增加。

英文释义：Guixu (The Great Abyss) / Oceanic Abyss / The Great Sinkhole

命名寓意：归墟的万物归一、永不枯竭，象征着各终端设备汇聚成统一共识网络，资源持续利用、生生不息。如同江河百川终归大海，每一位拥有闲置设备的人，都是构建去中心化世界的参与者。

核心理念

「资源即算力，贡献即共识。」
不再需要昂贵的矿机和服务器集群。每一台闲置电脑、每一部闲置手机，只要保持在线、贡献带宽、提供存储、稳定运行，就是区块链共识网络的一个有效节点。

项目愿景

构建一个真正基于分布式终端资源的区块链共识系统，让每一位拥有闲置设备的人，都能平等地参与区块链网络的建设并获得回报。零门槛、无私募、不公募、去中心化。

第二章 系统设计理念

核心思路

闲置终端设备 → 贡献带宽/存储/算力 → 贡献值计算 → 通证奖励分配

资源类型与贡献模型

系统根据终端设备实际贡献的资源类型，分别记录贡献值。每种资源类型有不同的贡献系数：

资源类型 贡献描述 采集方式
网络带宽利用闲置带宽参与节点间通信、数据同步、网络转发流量计量器 + 连通性检测
存储空间为网络提供分布式存储节点，存储区块数据、应用数据磁盘使用量 + 可用性检测
计算能力闲置CPU/GPU算力参与共识计算、数据验证、智能合约执行CPU周期检测 + GPU占用监控
稳定性设备在线时长、连续运行时间、网络波动容忍度心跳检测 + 在线日志
地理位置多终端分布于不同地理区域，提升网络抗单点故障能力IP地理位置标注

终端角色分类

终端类型 PC电脑端 手机端 主要贡献
家用电脑✅ 主端—存储 + 带宽 + 算力
手机—✅ 轻端带宽 + 轻量存储 + 移动节点
服务器/NAS✅ 重端—高带宽 + 大存储 + 高算力
移动设备（车载/穿戴）—✅ 轻端移动带宽 + 位置贡献

资源对接与商业闭环

归墟共识网络聚合的闲置资源并非仅在网络内部记账，而是通过标准化接口直接对接真实需求方的实体平台，形成"贡献 — 聚合 — 对接 — 变现 — 反哺"的完整商业闭环。这是归墟区别于纯概念型网络的核心生存能力：资源始终有真实买家。

资源类型对接需求方实体平台变现路径
磁盘存储专业存储服务商、分布式云存储与备份归档服务商企业级备份、冷数据归档、对象存储容量租赁
带宽资源CDN 服务商、边缘计算网络、矿业资源运营商流量分发、节点加速、带宽资源租赁（含挖矿相关用途）
终端算力AI 训练与推理服务商、渲染及科学计算平台GPU / CPU 算力租赁、模型推理托管
流量与网络效应通证持有者、生态应用方、通证二级市场流量聚合本身即形成通证经济效益

除三类实体资源的直接变现外，网络规模的增长本身即构成独立的商业价值。随着接入终端与活跃地址持续增加，平台所积聚的流量、用户注意力与交易活跃度本身就可以形成通证经济效益：交易税与转账税持续注入运维基金，网络活跃度提升带动通证需求，最终形成"资源贡献者 — 需求方 — 通证持有者"三方正向循环。

第三章 通证经济模型

通证基础信息

归墟共识网络通证（以下简称「归墟代币」），是社区成员参与共识网络建设并获得贡献奖励的唯一凭证。该通证通过合约内置的「交易税」和「转账税」机制，持续为运维基金提供资金支持。

通证发行规则

项目 规则
发行总量按需铸造，无固定总量上限，由系统贡献值动态决定发行速度
发行方式无私募、无公募，全部通过终端资源贡献自动铸造
分配机制按终端资源贡献值比例分配，贡献越多，奖励越多
铸造触发条件终端持续贡献资源达一定阈值时，自动铸造并分配
铸造冷却每次铸造间隔1小时，防止频繁小额铸造

税务机制 — 运维基金

交易税：每笔交易（Transfer）收取 1% 的归墟代币作为交易税。
转账税：每笔转账收取 0.5% 的归墟代币作为转账税。
防机器人策略：税率刻意设定较高，大幅提高自动化脚本批量刷量、薅羊毛的成本，保护真实持币用户的权益。
税率说明：税率可在社区治理中投票调整，确保费率既能提供足够的运维资金，又不会过高影响用户体验。
基金去向：所有税费收入自动转入运维基金池，用于节点奖励发放、网络维护、安全审计和系统升级。

贡献值计算模型

贡献值 = ∑(资源类型 × 贡献系数 × 贡献时长 × 稳定性权重 × 防作弊系数)

防薅羊毛与反作弊

为防止自动化脚本、AI代理和恶意用户大量制造虚假终端进行薅羊毛，系统内置多层防御机制：

防御策略实现方式目的
设备指纹终端唯一识别码（设备ID + 网络环境指纹），同一设备重复贡献不叠加防止单设备多账号
贡献衰减曲线新设备贡献值初始系数为1.0，连续在线超过30天后系数逐步提升至1.5，防止短期刷量防止短期大量刷取
行为分析异常行为检测：非人类规律的操作频率、异常贡献曲线、自动化脚本模式识别检测自动化脚本
资源真实性验证带宽使用量与设备性能匹配度验证，异常贡献值触发人工审核防止性能不匹配
地理位置校验同一IP段多终端注册触发限流，异地IP频繁变更触发警告防止分布式虚假节点
社区举报机制用户可举报异常贡献者，经社区投票确认后可扣除贡献值社区共治

第四章 技术架构

架构概览

系统采用「去中心化节点 + 链上记账 + 链下验证」三层架构，确保系统安全与可扩展性。

层级 功能 技术
终端层终端设备资源贡献、数据采集、本地验证PC客户端 / 手机App / 浏览器插件
共识层贡献值计算、节点权重评估、通证铸造分布式共识算法（资源贡献加权的PoR）
链上账本贡献记录存储、通证分配、税务征收、链上治理智能合约 + 链上账本
应用层贡献面板、通证钱包、社区投票、运维基金查询Web前端 + 移动端App

共识算法 — PoR (Proof of Resource)

传统PoW消耗大量电力，PoS依赖资金锁定。归墟共识网络采用PoR（资源证明，Proof of Resource）共识机制：以资源贡献替代资本质押与算力竞赛，是区别于PoW/PoS的独立路径；技术实现借鉴PoS的权益加权思路，但权重来源是资源贡献而非代币质押。

  • 终端通过持续贡献闲置资源（带宽、存储、算力）来证明其贡献价值
  • 系统实时计算各终端的贡献值排名
  • 贡献值排名靠前的终端，优先获得通证铸造权
  • 所有资源贡献记录在链上，不可篡改

第五章 运营与治理

社区治理

系统完全去中心化治理，所有重大决策由归墟代币持有者投票决定：

  • 税率调整（交易税1%、转账税0.5%的修改）
  • 贡献系数调整（各资源类型权重的变更）
  • 运维基金使用审批
  • 技术升级与协议变更
  • 恶意节点处罚

运维基金

资金来源：交易税（1%）+ 转账税（0.5%），持续流入。
资金用途：
  • 节点奖励发放（40%）
  • 网络维护与安全审计（30%）
  • 系统升级与开发（20%）
  • 社区建设与市场推广（10%）
资金监管：所有资金流动全链上透明可查，定期发布基金报告。

第八章 结语

归墟共识网络不是一个关于未来的概念，而是关于现实的思考：在数字时代，每个人的闲置资源都是一种被浪费的财富。当这些资源汇聚在一起，足以支撑一个去中心化的区块链网络。

我们相信，真正的去中心化不是口号，而是实践。不需要昂贵的矿机，不需要巨大的资金门槛，只需要你的闲置设备、你的闲置带宽、你的闲置存储。这些资源，就是你的筹码，就是你的贡献，就是你对去中心化世界的投票。

归墟共识网络——万流归一，共筑共识。

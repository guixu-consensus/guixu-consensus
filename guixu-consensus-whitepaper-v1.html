开篇说明 · 平台定位与价值阐述

一、平台定位：一张资源价值网

归墟共识网络不是一个单纯的 DApp 或工具，而是一张资源价值网——它的核心使命，是把散落在用户闲置设备与闲置注意力中的物理资源与流量资源汇聚起来，对接真实商业需求，形成一个可持续流转的商业闭环。

二、双层资源模型

物理资源：用户闲置的设备（PC、手机、路由器、边缘节点等）本身具备可计算、可存储、可传输的能力。这些能力在归墟网络中被调度为算力节点、存储节点、带宽节点与边缘计算节点。物理资源的价值没有上限——用户设备越多、越空闲，平台可调用的物理底座就越庞大。

流量资源：用户的注意力、访问行为、社交关系与内容消费路径，都是流量。归墟通过终端入口（node.guixu.club）、桌面端（desktop）、移动端（mobile）构建多触点触达，把用户的活跃行为转化为可度量的流量池。流量资源的价值同样没有上限——用户基数越大、粘性越强、内容生态越丰富，流量池的商业定价空间就越大。

三、通证经济作为价值锚点

通证（Token）不是目的，而是价值共识的载体。归墟的运作分为三个阶段：

  • 阶段一 · 通证引流，搭建共识：用通证经济作为钩子——参与即得、贡献即奖、持有即受益——吸引早期用户。通证在这里的作用是降低信任成本：用户不需要理解复杂的底层技术，只需要知道「我参与，我受益」。
  • 阶段二 · 通证支撑商业，汇聚价值：当用户规模达到临界点，通证开始发挥商业锚定作用——物理资源贡献者获得通证奖励，形成持续参与的激励；流量资源产生者（终端用户）通过行为获得通证回馈；商业需求方通过通证体系购买平台资源。通证成为衡量资源价值的通用标尺，使物理资源与流量资源可以在同一套估值体系下被定价和交易。
  • 阶段三 · 通证退出，商业闭环独立运转：当平台成熟后，通证的角色从「吸引器」转变为「结算器」。商业闭环不再依赖通证本身作为目的，而是通证作为价值流转的媒介，确保每个参与者的贡献都能获得合理回报。

四、商业闭环

用户闲置设备 + 用户注意力 → 归墟终端（入口层） → 物理资源汇聚（算力/存储/带宽）＋ 流量资源汇聚（访问/行为/社交） → 通证激励绑定 ＋ 通证行为回馈 → 归墟共识网络（价值中枢） → 商业需求方（企业/开发者/项目方） → 资源变现（物理资源出售）＋ 流量变现（广告/推广/分销） → 通证分发（奖励贡献者） → 用户继续贡献，形成正循环

这个闭环的关键在于可持续性——物理资源不会因为消耗而减少（相反，设备越用越成熟，网络越用越庞大），流量资源也不会因为变现而枯竭（用户的商业行为可以反哺用户，形成更多贡献）。通证作为润滑剂，确保价值在贡献者、平台、需求方之间公平流转。

归墟共识网络聚合的闲置资源并非仅在网络内部记账，而是通过标准化接口直接对接真实需求方的实体平台，形成"贡献 — 聚合 — 对接 — 变现 — 反哺"的完整商业闭环。这是归墟区别于纯概念型网络的核心生存能力：资源始终有真实买家。

资源类型对接需求方实体平台变现路径

带宽资源CDN 服务商、边缘计算网络、矿业资源运营商流量分发、节点加速、带宽资源租赁（含挖矿相关用途）

除三类实体资源的直接变现外，网络规模的增长本身即构成独立的商业价值。随着接入终端与活跃地址持续增加，平台所积聚的流量、用户注意力与交易活跃度本身就可以形成通证经济效益：交易税持续注入运维基金，网络活跃度提升带动通证需求，最终形成"资源贡献者 — 需求方 — 通证持有者"三方正向循环。

五、价值阐述总结

归墟共识网络的价值不是单一维度的。它是一个从用户闲置出发、以通证为共识基石、以资源汇聚为手段、以商业闭环为目标的完整体系。

  • 对用户：把闲置变成收益，把注意力变成价值，把参与变成权益。
  • 对商业方：以通证为信用媒介，以平台为信用载体，获取精准、可度量、可持续的流量与算力资源。
  • 对平台：不卖资源、不囤资源，而是搭建一个让资源自然汇聚、自然定价、自然流转的价值基础设施。

商业的终局不是榨取，而是共赢的持续循环。归墟想做的，就是让每一次贡献、每一次访问、每一次交易，都能在这个循环中找到自己的位置。

第一章 项目背景与愿景

2026年，算力仍在矿场集中，节点仍在服务器集群中沉默运转。普通人的闲置电脑、手机、宽带上限与存储空间，从未被纳入区块链的共识网络。算力与网络的集中化，让去中心化的口号在现实中变得苍白。

归墟共识网络，诞生于这样一个朴素的信念：真正的去中心化，不应该要求任何人放弃自己的设备。每个人手头的闲置资源，本身就是区块链最需要的共识力量。

命名释义

归墟 (Guixu) · The Great Abyss

归墟是中国古代神话概念，最早见于《列子·汤问》。归墟指海水汇聚的无底之渊，所有江河最终汇入归墟，但归墟的水量却永不增加。

英文释义：Guixu (The Great Abyss) / Oceanic Abyss / The Great Sinkhole

命名寓意：归墟的万物归一、永不枯竭，象征着各终端设备汇聚成统一共识网络，资源持续利用、生生不息。如同江河百川终归大海，每一位拥有闲置设备的人，都是构建去中心化世界的参与者。

核心理念

「资源即算力，贡献即共识。」
不再需要昂贵的矿机和服务器集群。每一台闲置电脑、每一部闲置手机，只要保持在线、贡献带宽、提供存储、稳定运行，就是区块链共识网络的一个有效节点。

项目愿景

构建一个真正基于分布式终端资源的区块链共识系统，让每一位拥有闲置设备的人，都能平等地参与区块链网络的建设并获得回报。零门槛、无私募、不公募、去中心化。

第三章 通证经济模型

通证基础信息

归墟共识网络通证（以下简称「gx」），是社区成员参与共识网络建设并获得贡献奖励的唯一凭证。该通证通过合约内置的「交易税」机制，持续为运维基金提供资金支持。

通证发行规则

项目 规则
发行总量按需铸造，无固定总量上限，由系统贡献值动态决定发行速度
发行方式无私募、无公募，全部通过终端资源贡献自动铸造
分配机制按终端资源贡献值比例分配，贡献越多，奖励越多
铸造触发条件终端持续贡献资源达一定阈值时，自动铸造并分配
铸造冷却每次铸造间隔1小时，防止频繁小额铸造

税务机制 — 运维基金

交易税：每笔交易（Transfer）收取 1% 的 gx 作为交易税。
防机器人策略：税率刻意设定较高，大幅提高自动化脚本批量刷量、薅羊毛的成本，保护真实持币用户的权益。
税率说明：税率可在社区治理中投票调整，确保费率既能提供足够的运维资金，又不会过高影响用户体验。
基金去向：所有税费收入自动转入运维基金池，用于节点奖励发放、网络维护、安全审计和系统升级。

贡献值计算模型

贡献值 = ∑(资源类型 × 贡献系数 × 贡献时长 × 稳定性权重 × 防作弊系数)

有效贡献者门槛

并非所有接入网络的终端都能产生有效的资源贡献。为确保网络整体资源质量，满足商业需求方的采购标准，系统对「有效资源贡献者」设有以下最低门槛：

评估维度最低要求说明
硬件门槛PC ≥ 4 核 CPU + 8GB 内存 + 50GB 可用存储；手机 ≥ 4GB RAM + 20GB 可用存储低于此门槛的终端贡献值上限封顶
网络带宽下行 ≥ 50Mbps，上行 ≥ 20Mbps（连续 7 天）贡献值系数 = 上行带宽 / 100Mbps，封顶 1.5
在线稳定性7 天内在线率 ≥ 90%不满足则当日贡献值清零
贡献值达标7 天累计贡献值 ≥ 100不同设备类型差异化基准：PC ≥ 200，手机 ≥ 100，服务器/NAS ≥ 500
分级激励：
Lv1 普通贡献者：满足上述四项 → 贡献值系数 1.0
Lv2 优质贡献者：上行带宽 ≥ 100Mbps 且连续在线 60 天 → 系数提升至 1.5
Lv3 核心贡献者：上行带宽 ≥ 500Mbps + GPU 参与共识 + 连续 180 天稳定 → 系数 2.0，享有治理投票权重 +1 倍

防薅羊毛与反作弊

为防止自动化脚本、AI代理和恶意用户大量制造虚假终端进行薅羊毛，系统内置多层防御机制：

防御策略实现方式目的
设备指纹终端唯一识别码（设备ID + 网络环境指纹），同一设备重复贡献不叠加防止单设备多账号
贡献衰减曲线新设备贡献值初始系数为1.0，连续在线超过30天后系数逐步提升至1.5，防止短期刷量防止短期大量刷取
行为分析异常行为检测：非人类规律的操作频率、异常贡献曲线、自动化脚本模式识别检测自动化脚本
资源真实性验证带宽使用量与设备性能匹配度验证，异常贡献值触发人工审核防止性能不匹配
地理位置校验同一IP段多终端注册触发限流，异地IP频繁变更触发警告防止分布式虚假节点
社区举报机制用户可举报异常贡献者，经社区投票确认后可扣除贡献值社区共治

第四章 技术架构

架构概览

系统采用「去中心化节点 + 链上记账 + 链下验证」三层架构，确保系统安全与可扩展性。

层级 功能 技术
终端层终端设备资源贡献、数据采集、本地验证PC客户端 / 手机App / 浏览器插件

链上账本贡献记录存储、通证分配、税务征收、链上治理智能合约 + 链上账本
应用层贡献面板、通证钱包、社区投票、运维基金查询Web前端 + 移动端App

共识算法 — PoR (Proof of Resource)

传统PoW消耗大量电力，PoS依赖资金锁定。归墟共识网络采用PoR（资源证明，Proof of Resource）共识机制：以资源贡献替代资本质押与算力竞赛，是区别于PoW/PoS的独立路径；技术实现借鉴PoS的权益加权思路，但权重来源是资源贡献而非代币质押。

  • 终端通过持续贡献闲置资源（带宽、存储、算力）来证明其贡献价值
  • 系统实时计算各终端的贡献值排名
  • 贡献值排名靠前的终端，优先获得通证铸造权
  • 所有资源贡献记录在链上，不可篡改

第九章 资源价值网运营规范

归墟共识网络不仅依赖物理资源的汇聚，更依赖对「人」和「行为」的精准定义。以下三个角色定义是网络商业闭环可持续运转的核心前提。

一、有效流量用户定义

归墟通过终端入口（node.guixu.club）、桌面端、移动端构建多触点触达，把用户的活跃行为转化为可度量的流量池。但流量资源必须排除机器人、自动挂机刷量，否则商业变现端（广告/推广/分销）将失去定价权。

一个访问行为被计入有效流量，必须同时满足以下全部条件：

判定维度标准技术实现
身份唯一性一个自然人一个钱包地址，且地址与设备指纹绑定钱包签名 + 设备指纹哈希（IP + User-Agent + 屏幕分辨率 + Canvas 指纹）；跨设备新建钱包需行为验证
非自动挂机访问行为有随机性、有停留、有交互，无固定脚本模式行为分析引擎：记录鼠标轨迹、滚动速度、按键间隔；偏离人类操作分布（如恒速滚动、固定间隔点击）自动降权
有效停留单次会话停留时间 ≥ 15 秒，且至少发生 1 次有意义的交互（点击、表单输入、路由跳转）前端埋点 + 后端聚合，15 秒阈值可在社区治理中调整
来源质量排除搜索引擎爬虫、CDN 预加载请求、已知代理池 IP爬虫检测 + 代理 IP 黑名单 + 反向 DNS 验证
防作弊分层：
L1（自动化脚本）：固定 IP 批量创建钱包、恒速操作 → 直接拦截，不产生贡献值
L2（真人 + 脚本辅助）：真人操作但使用自动化工具 → 行为偏离人类分布，贡献值系数降至 0.3
L3（完全真人）：贡献值系数 1.0，连续有效在线 30 天后系数逐步升至 1.5

二、有效资源贡献者定义

系统根据终端设备实际贡献的资源类型分别记录贡献值。但并非所有接入网络的终端都能产生有效的资源贡献。为确保网络整体资源质量、满足商业需求方的采购标准，一个终端在 7 天评估周期内必须同时满足以下四项，才定义为「有效资源贡献者」：

维度最低要求说明
硬件门槛PC ≥ 4 核 CPU + 8GB 内存 + 50GB 可用存储；手机 ≥ 4GB RAM + 20GB 可用存储；路由器/网关 ≥ 256MB RAM低于此门槛的终端贡献值上限封顶，不视为有效贡献者
网络带宽下行 ≥ 50Mbps，上行 ≥ 20Mbps（至少连续 7 天）贡献值系数 = 上行带宽 / 100Mbps，封顶 1.5
在线稳定性7 天内在线率 ≥ 90%（每天在线 ≥ 18 小时）不满足则当日贡献值清零
贡献值达标7 天累计贡献值 ≥ 100差异化基准：PC ≥ 200，手机 ≥ 100，服务器/NAS ≥ 500
分级激励：
Lv1 普通贡献者：满足上述四项 → 贡献值系数 1.0
Lv2 优质贡献者：上行带宽 ≥ 100Mbps 且连续在线 60 天 → 系数提升至 1.5
Lv3 核心贡献者：上行带宽 ≥ 500Mbps + GPU 参与共识 + 连续 180 天稳定 → 系数 2.0，享有治理投票权重 +1 倍

三、市场推广者定义（团队长）

归墟共识网络无私募、无公募，但需要市场推广。团队长不能是「拉人头吃提成」的传销模式，也不能是「躺赚分润」破坏 PoR 共识的去中心化原则。推广激励通过「贡献值加成 + 团队活跃奖励」实现，而非「直接通证分润」。

同时满足以下条件的角色，定义为有效团队长：

维度判定标准说明
招募规模直接邀请 ≥ 10 个有效资源贡献者（Lv1 及以上）加入归墟网络仅有效贡献者计入，无效流量/零贡献注册不计
团队质量团队成员中 ≥ 30% 为 Lv2 优质贡献者防止刷低配设备充数
个人参与团队长本人也必须是有效资源贡献者（Lv1 及以上）避免纯拉新模式
持续活跃过去 30 天内团队整体日均活跃终端 ≥ 15 个防止一次性拉新后团队解散

激励方案（三个层级，逐层解锁）：

层级一 · 招募奖励（一次性）：每招募 1 个 Lv1 有效贡献者 → 贡献值加成 +5%；每招募 1 个 Lv2 → +15%；每招募 1 个 Lv3 核心贡献者 → +30%。加成仅对团队长个人贡献值生效，不影响网络整体发行速度。

层级二 · 团队活跃奖励（持续）：团队日均活跃终端 ≥ 20 个 → 额外获得团队总贡献值的 0.5%（从运维基金 10% 社区推广预算支付）；≥ 50 个 → 提至 1.0%。按月发放，不计入通证发行。

层级三 · 生态贡献奖励（长期）：团队成员贡献的资源被商业需求方采购后，团队长获得采购额的 1%（从商业化收入支出，不计入通证发行），仅对 Lv2+ 成员产生的采购有效。

防作弊关键机制：

风险防范措施
团队长用脚本批量制造假贡献者团队成员必须满足「有效流量用户」定义（行为分析引擎），脚本账号贡献值归零
团队长拉低配设备充数Lv2/Lv3 加成仅对真实有效贡献者生效，低配设备贡献值封顶
团队解散后继续领取奖励持续活跃考核：30 天无活跃则奖励资格暂停，重新激活需 7 天考核
团队长自拉自奖团队成员须完成 KYC/设备绑定，同一自然人不得同时作为团队长和团队成员

三个角色的设计核心逻辑：

  • 有效流量用户 — 确保流量池是真实人类，商业变现端有定价权
  • 有效资源贡献者 — 确保物理资源池质量达标，商业需求方愿买单
  • 市场推广者 — 用贡献值加成替代直接分润，保持 PoR 共识公平性，同时激励社区增长

Chapter 1: Project Background & Operations Status

1.1 Project Background

In 2026, the blockchain industry is facing three major bottlenecks: compute centralization, high barriers to entry, and energy waste. The compute power of existing public chains is monopolized by professional mining farms, PoW mining consumes massive electricity, and PoS requires large token stakes—none of which align with the original intent of decentralization.

The Guixu Consensus Platform proposes a brand-new approach: true decentralization does not require users to invest in purchasing mining rigs, but instead allows every person with idle devices to participate in the consensus network. Idle computers, phones, routers, and NAS—these resources themselves are the consensus power that blockchain most desperately needs.

1.2 Project Positioning

Project Nature: Decentralized consensus network platform
Core Mechanism: PoR (Proof of Resource) Resource Proof Consensus
Token Type: Guixu Token
Operations Mode: Community Co-Governance, on-chain governance, fully transparent on-chain

The project is currently in the foundational concept phase, with whitepaper completed in Chinese and English. PoR algorithm prototype validation and beta testing are planned for Q1-Q2 2027, mainnet launch for Q3, and open phase for Q4.

Chapter 3: Community Governance Mechanism

3.1 PoR Consensus Mechanism

The Guixu Consensus Platform adopts the PoR (Proof of Resource) consensus mechanism: it replaces capital staking and hashrate competition with resource contribution, establishing an independent path distinct from PoW and PoS; the technical implementation draws on PoS's stake-weighting approach, but the weight derives from resource contribution rather than token staking.

Idle Terminals → Contribute Resources → Calculate Score → Rank & Mint
  • Terminals prove their contribution value through continuous contribution of idle resources (bandwidth, storage, compute)
  • The system real-time calculates each terminal's contribution score ranking
  • Terminals with the highest contribution scores gain priority in token minting rights
  • All resource contribution records are stored on-chain, immutable

3.2 Token Issuance Mechanism

3.3 Tax Mechanism — Operations Reserve Fund

Transaction Tax: 1% Guixu token per transaction (Transfer)
Transfer Tax: 0.5% Guixu token per transfer
Rate Adjustment: Tax rates can be adjusted via community governance voting
Fund Destination: Transaction and transfer tax revenue automatically flows into the operations reserve pool

Fund Usage Allocation: Node rewards (40%), network maintenance & security audits (30%), system upgrades & development (20%), community building & marketing (10%)

3.4 Community Governance Voting

Guixu token holders participate in community governance through on-chain voting. Key voting items include:

  • Tax rate adjustments (modification of 1% transaction tax and 0.5% transfer tax)
  • Contribution coefficient adjustments (changes to weights for each resource type)
  • Operations reserve fund usage approval
  • Technology upgrades and protocol changes
  • Malicious node punishment

4.4 Resource Integration & Commercial Loop

Standardized integration channels have been planned for the idle resources aggregated by the platform, delivering directly to real-world demand-side platforms so that resources always have somewhere to go and a price to realize. Operations advance along separate lines by resource type:

Resource TypeIntegration DirectionOperations Action
Disk storageProfessional storage providers, distributed cloud storage / backup & archive platformsSign capacity purchase agreements; settle by available capacity and online duration
BandwidthCDN providers, edge networks, mining resource operatorsPackage idle bandwidth pools; lease by traffic / duration (including mining-related use)
Terminal computeAI training & inference providers, rendering and scientific computing platformsConnect compute scheduling; bill and settle per task
Traffic & ecosystemToken holders and ecosystem applicationsAccumulated traffic forms token economic value; taxes feed the Operations Reserve Fund

These integrations constitute the commercial survival foundation of the project: even amid token price volatility, genuine demand for the underlying resources continues to generate revenue that feeds the Operations Reserve Fund and sustains long-term network operations. Meanwhile, the traffic and user attention accumulated by the platform itself can form token economic value, complementing resource monetization within the revenue structure.
